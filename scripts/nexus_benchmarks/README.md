# Computational benchmark scripts

These Python scripts provide runnable, profiled examples of common Roman science workloads described in the [Computational Benchmarks article](https://roman-docs.stsci.edu/data-handbook/roman-research-nexus/benchmarking-examples-and-estimated-costs-on-the-roman-research-nexus) on RDox: RomanCal exposure and mosaic pipelines, Roman I-Sim simulations, source detection and photometry, galaxy-shape measurements, Astrocut image cutouts, Pandeia exposure-time calculations, and catalog cross-matching. Numbered `case1()`, `case2()`, etc., the functions in each script represent distinct benchmark scenarios or input sizes; run the case matching the operation and configuration you want to measure. `profile_workflows.py` supplies the shared resource-profiling helper used to return a workload’s result alongside CPU, memory, and wall-clock time metrics.

Use the measurements to compare these defined workloads and help estimate Roman Research Nexus compute needs—not as fixed guarantees for other data or configurations. Results depend on input size and source distribution, file I/O, software versions, available memory, and parallelism; CPU hours measure total compute consumed and are distinct from wall-clock time.
