# Science Workflows

Science Workflows in the Nexus organize related [Notebook Tutorials](./tutorials.md) into guided, end-to-end examples that show how individual tools and analysis steps connect into a broader scientific task. Each workflow provides a structured path through a specific use case, while the underlying tutorials remain available as standalone examples that users can adapt to their own projects.

Workflows are designed to help users work with Roman data in the Nexus environment, using the software, data structures, and analysis and simulation tools available on the platform.
## WFI Workflows

The Nexus currently includes six WFI-focused Science Workflows:

- [Roman Data Essentials](./workflows/Intro_Workflow.md) — Get an entry-level introduction to the foundational tools and concepts for discovering, accessing, understanding, and visualizing Roman data.
- [WFI Data Simulation](./workflows/wfi-data-sim.md) — Simulate Roman WFI imaging products and process them through the official WFI imaging processing pipeline.
- [WFI Data Analysis](./workflows/wfi-data-analysis.md) — Discover, visualize, and analyze WFI imaging and spectroscopic data.
- [WFI Observation Planning](./workflows/wfi-obs-plan.md) — Evaluate exposure times, instrument performance, survey geometry, and observing strategies.
- [WFI Reference File Exploration](./workflows/crds-reference-files.md) — Retrieve and inspect reference files used to calibrate Roman WFI data.
- [Time Domain](./workflows/time-domain.md) — Simulate and analyze time-variable sources.

Together, these workflows demonstrate how Roman tools can be used for pipeline-level data simulation, exploration and analysis of WFI data products, assessment of guiding performance, exploration and validation of calibration reference products, proposal planning, and time-domain studies of transients and variable sources. They highlight different aspects of the Roman ecosystem, from accessing Roman data through MAST, generating synthetic datasets, and processing data through the Roman calibration pipeline to performing photometric measurements across epochs and evaluating observing strategies. While the current materials focus primarily on WFI imaging applications, they also include an introductory spectroscopic example within the WFI Data Analysis workflow, with additional spectroscopy-focused content planned for future releases.
## Using Workflows
Workflows are composed of individual [Notebook Tutorials](./tutorials.md), each focused on a specific tool or analysis step. Users may work through an entire workflow sequentially or use the tutorials independently, depending on their goals.
